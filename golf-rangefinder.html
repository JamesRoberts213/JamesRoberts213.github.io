A self-contained, battery-powered embedded electronics system combining real-time GNSS satellite positioning, high-contrast SPI display rendering, and custom FDM 3D-printed mechanical packaging.

System Overview

Commercial golf rangefinders often rely on expensive optical laser assemblies or bulky smartwatches. This project explores a low-cost, dedicated embedded alternative capable of calculating real-time Haversine yardage to front, center, and back green coordinates stored locally in flash memory.

The hardware architecture was prototyped on perfboard with point-to-point soldering, housed inside a custom SolidWorks-designed PLA enclosure featuring heat-set brass threaded inserts for serviceable field assembly.

Hardware Architecture & Bill of Materials

Subsystem Component Interface & Technical Role
Microcontroller Arduino Nano (ATmega328P) Parses NMEA sentences, executes Haversine distance calculations ($R = 6371\text{ km}$), and drives UI state machine.
Display Module 2.0" ST7789V IPS TFT LCD $240 \times 320$ resolution driven over 4-wire hardware SPI with level-shifted logic lines.
Positioning UART GNSS/GPS Receiver 9600 baud serial communication streaming real-time latitude/longitude telemetry.
Power Management TP4056 + 3.7V Li-Ion Cell Integrated constant-current/constant-voltage charging with over-discharge protection and boost regulation.
User Input Perfboard Tactile Switches Hardware-debounced interrupt/polling inputs for hole selection and green target toggling.
Enclosure FDM 3D-Printed PLA Shell Custom CAD housing with M2.5 heat-set brass inserts ($210^\circ\text{C}$ installation) for mechanical rigidity.

Key Engineering Takeaways

SRAM Optimization on ATmega328P

Constrained dynamic memory ($2\text{ KB}$ SRAM) required storing course coordinate lookup tables in `PROGMEM` flash memory and avoiding dynamic `String` heap fragmentation during SPI screen refreshes.

3.3V / 5V Logic Level Shifting

Protected the 3.3V ST7789V display controller from 5V Arduino logic levels using resistive voltage dividers on the SPI clock and data lines to ensure long-term signal integrity.

Design for Assembly (DFA) in FDM

Learned how wall thickness around bosses affects melt flow when installing heat-set brass inserts at $210^\circ\text{C}$, preventing exterior surface bulging on thin PLA walls.

NMEA Parsing & Cold-Start Filtering

Implemented dilution-of-precision (HDOP) filtering in firmware to prevent erratic yardage jumps while the GNSS receiver acquires initial satellite lock.
