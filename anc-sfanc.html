Research Scope & Motivation

Overcoming Classical FxLMS Bottlenecks

Conventional linear Filtered-x LMS (FxLMS) controllers struggle with slow convergence during rapid non-stationary noise transients, loudspeaker saturation, and nonlinear primary acoustic paths. This research synthesizes three core mechanisms into a unified cabin ANC architecture:

  • Zero-Latency SFANC Switching: A lightweight neural classifier inspects incoming noise frames and selects optimal pre-trained control filter weights instantaneously via ONNX runtime.
  • Nonlinear FLANN Expansion: Trigonometric functional expansion ($\sin(k\pi x), \cos(k\pi x)$) captures harmonic distortion and nonlinear primary/secondary path dynamics without deep multi-layer latency.
  • Multi-Sensor Reference Fusion: Combines reference microphones with structural accelerometers to preserve causality on structure-borne cabin noise.

Mathematical & Control Formulation

1. FLANN Trigonometric Basis Expansion

$$\mathbf{\Phi}(x(n)) = \Big[x(n),\, \sin(\pi x(n)),\, \cos(\pi x(n)),\, \dots,\, \sin(P\pi x(n)),\, \cos(P\pi x(n))\Big]^T$$

Projects the scalar reference signal into a higher-dimensional nonlinear feature space, enabling a single-layer adaptive filter $y(n) = \mathbf{w}^T(n)\mathbf{\Phi}(x(n))$ to cancel harmonic distortion.

2. Hybrid SFANC + FxNLMS Weight Update

$$\mathbf{w}(n+1) = \mathbf{w}(n) - \frac{\mu}{\|\mathbf{\Phi}'(n)\|_2^2 + \delta}\, e(n)\,\mathbf{\Phi}'(n), \quad \mathbf{w}(0) = \mathbf{w}_{\text{ONNX}}$$

Initializes weights from the ONNX neural classifier ($\mathbf{w}_{\text{ONNX}}$) and adapts online using the filtered expanded vector $\mathbf{\Phi}'(n) = \hat{s}(n) * \mathbf{\Phi}(x(n))$.

3. Secondary Path Phase Misalignment Bound

$$\text{Re}\left\{ S(e^{j\omega})\,\hat{S}^*(e^{j\omega}) \right\} > 0 \iff |\phi_S(\omega) - \phi_{\hat{S}}(\omega)| < 90^\circ$$

Strict Lyapunov / mean-square stability condition: if phase mismatch between the true secondary path $S(z)$ and internal model $\hat{S}(z)$ exceeds $\pm 90^\circ$, negative feedback flips to positive instability.

sfanc_selector_onnx.py — PyTorch CUDA Classifier & ONNX Export 
import torch
import torch.nn as nn

class SFANCFilterSelector(nn.Module):
    """Lightweight 1D-CNN selector mapping acoustic reference frames to pre-trained FLANN filter indices."""
    def __init__(self, frame_len: int = 256, num_filters: int = 12):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv1d(1, 16, kernel_size=7, stride=2, padding=3),
            nn.BatchNorm1d(16),
            nn.ReLU(),
            nn.Conv1d(16, 32, kernel_size=5, stride=2, padding=2),
            nn.BatchNorm1d(32),
            nn.ReLU(),
            nn.AdaptiveAvgPool1d(8)
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(32 * 8, 64),
            nn.ReLU(),
            nn.Linear(64, num_filters)
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # x shape: (batch, 1, frame_len)
        return self.classifier(self.features(x))

def export_selector_to_onnx(weights_path: str, onnx_out: str = "sfanc_selector.onnx"):
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    model = SFANCFilterSelector(frame_len=256, num_filters=12).to(device)
    model.load_state_dict(torch.load(weights_path, map_location=device))
    model.eval()

    dummy_frame = torch.randn(1, 1, 256, device=device)
    torch.onnx.export(
        model,
        dummy_frame,
        onnx_out,
        input_names=["ref_frame"],
        output_names=["filter_logits"],
        dynamic_axes={"ref_frame": {0: "batch"}, "filter_logits": {0: "batch"}},
        opset_version=14
    )
    print(f"Exported SFANC ONNX selector to {onnx_out}")
flann_sfanc_step.m — Simulink Nonlinear Adaptive Filter Step 
function [y_anti, w_next] = flann_sfanc_step(x_buf, e_n, w_curr, s_hat, P_order, mu, delta)
% FLANN-SFANC Nonlinear Filtered-x NLMS Control Step
% x_buf   : Tap-delay reference vector [N x 1]
% w_curr  : Warm-started weights from ONNX selector bank
% s_hat   : Estimated secondary path impulse response [M x 1]

    % 1. Functional Link Trigonometric Expansion (Order P)
    phi = x_buf;
    for p = 1:P_order
        phi = [phi; sin(p * pi * x_buf); cos(p * pi * x_buf)];
    end

    % 2. Compute Anti-Noise Control Output
    y_anti = w_curr' * phi;

    % 3. Filter Expanded Basis Through Secondary Path Estimate S_hat(z)
    phi_filt = filter(s_hat, 1, phi);

    % 4. Normalized FxNLMS Weight Adaptation
    norm_factor = (phi_filt' * phi_filt) + delta;
    w_next = w_curr - (mu / norm_factor) * e_n * phi_filt;
end

Key Research Insights

Eliminating Cold-Start Convergence Lag

Using a neural network solely to select pre-trained filter weights (SFANC) rather than generating raw audio samples per tick keeps inference lightweight while achieving millisecond transient response.

Harmonic Cancellation via FLANN

Linear FIR filters cannot cancel 2nd and 3rd harmonics generated by loudspeaker saturation or nonlinear structural paths; trigonometric FLANN expansion resolves this with a single adaptive weight vector.

Strict $\pm 90^\circ$ Secondary Path Margin

Thermal or geometric shifts in a cabin alter the secondary acoustic path $S(z)$; maintaining phase error below $90^\circ$ is essential to prevent positive feedback divergence.

Accelerometer + Microphone Fusion

Fusing structural accelerometer signals with reference microphones provides earlier mechanical lead time for structure-borne road/engine noise, preserving controller causality.
